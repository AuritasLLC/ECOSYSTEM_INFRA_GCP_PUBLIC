# ASM+ 1.1.1 candidate

This maintenance candidate corrects three issues found during the first private
Marketplace deployment of version 1.1.0:

- The ASM+ migration Job now runs the compiled migration entry point directly
  with Node.js because the hardened application image intentionally does not
  include the npm CLI.
- Top-level Kubernetes resources use the Marketplace application instance name
  as their common `app.kubernetes.io/name` label so the GKE Applications page
  can discover and group every component.
- The ASM+ application API receives both `CORS_ALLOWED_ORIGINS` and
  `CORS_ORIGINS`, preventing browser requests from failing when the runtime
  expects the newer environment-variable name.

The application container contents are unchanged from version 1.1.0. Release
images are retagged as 1.1.1 and the deployer was rebuilt from this source.
