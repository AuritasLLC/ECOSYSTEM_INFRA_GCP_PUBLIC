# Security and support

Do not publish passwords, access tokens, secret payloads, private keys,
infrastructure state files, unredacted logs, or customer documents in this
repository or in a public GitHub issue.

For ASM+ deployment, BYOL licensing, configuration, security, or operational assistance, use
the [Auritas contact page](https://www.auritas.com/contact-us/) or email
`connect@auritas.com`. Include the Marketplace product and release, customer
project ID, GKE cluster and namespace, approximate failure time and time zone,
and sanitized error messages.

Access to Kubernetes Secrets, BYOL license material, database backups, Cloud
Storage content, and support artifacts must follow the customer's approved
privileged-access and data-handling processes.
